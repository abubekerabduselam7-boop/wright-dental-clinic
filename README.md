# Wright Dental Clinic – Kansanga Website

A responsive, static HTML/CSS/JavaScript website prepared for Wright Dental Clinic, Kansanga, Kampala.

## Recommended free deployment

This project is intentionally static, so it can be hosted on GitHub Pages without Python or a database.

### GitHub Pages
1. Create a new GitHub repository, e.g. `wright-dental-clinic`.
2. Upload `index.html` and the `assets` folder.
3. Open **Settings → Pages**.
4. Select **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. GitHub will publish the site.

GitHub Pages supports publishing static files from a repository.

## Important before publishing

The site contains public information gathered from the clinic's online presence, but several details should be confirmed with the clinic before going live:
- Exact opening hours / emergency hours
- Whether Salaama Road branch is currently operating
- Current services and pricing
- Doctor/team names and qualifications
- Patient/review wording
- Photos and permission to use them
- Any claims such as 2,000+ patients or 5+ years

Do not add confidential patient information to a public GitHub repository.
